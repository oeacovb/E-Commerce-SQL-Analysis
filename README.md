# E-Commerce SQL Analysis

## Project Overview

This project analyzes an e-commerce dataset using SQL to generate
business insights related to sales, customers, products, sellers,
orders, payments and reviews.

## Objectives

The main objective is to answer business questions using SQL and
identify useful patterns in e-commerce performance.

## SQL Skills Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- JOINs
- Aggregate Functions
- CASE Statements
- Subqueries
- CTEs
- Window Functions
- RANK()
- LAG()
- Cumulative Analysis

## Business Questions

1. Analyze overall sales performance
2. Analyze customer purchasing behavior
3. Identify top-performing products
4. Analyze seller performance
5. Analyze monthly order trends
6. Analyze payment methods
7. Analyze product categories
8. Analyze customer spending
9. Analyze revenue contribution
10. Analyze delivery performance

## Conclusion

The project demonstrates how SQL can be used to transform
e-commerce data into meaningful business insights and support
data-driven decision making.
